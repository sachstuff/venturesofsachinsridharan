# Ventures of Sachin Sridharan - Website

A professional, modern website showcasing the ventures and innovation initiatives of Sachin Sridharan, featuring two main ventures: **Makerslite Laboratory** and **Neuromorphic Systems**.

## 🚀 Features

### Pages
- **Home Page** (`index.html`) - Overview of all ventures, mission statement, and call-to-action buttons
- **Makerslite Laboratory** (`makerslite.html`) - Detailed information about hardware innovation and prototyping
- **Neuromorphic Systems** (`neuromorphic.html`) - Comprehensive details on bio-inspired computing and AI research
 - **Makerslite Laboratory** (`makerslite.html`) - An open-source virtual R&D lab game and online research community for collaborative simulation, prototyping, and reproducible research
 - **Neuromorphic Systems** (`neuromorphic.html`) - Comprehensive details on bio-inspired computing and AI research
 - **Videos of Sachin Sridharan** (`videos.html`) - A polymathic collection of talks, tutorials, demos, and interviews by Sachin Sridharan spanning engineering, AI, design, and open-source research. YouTube channel: https://www.youtube.com/@videosofsachinsridharan

## 🔧 How to Use

### Opening the Website
1. Open any of the `.html` files in your web browser
2. Navigate between pages using the navigation menu
3. Use the call-to-action buttons to jump between ventures

### Customization

#### Modify Contact Information
Edit the contact section in `index.html`:
```html
<a href="mailto:sachin.srithar@gmail.com">sachin.srithar@gmail.com</a>
```

#### Update Social Media Links
In `index.html`, update the social links:
```html
<a href="https://www.linkedin.com/in/sachin-sridharan-92b136120/" target="_blank">LinkedIn</a>
```

#### Change Colors
Modify CSS variables in `styles.css`:
```css
:root {
    --primary-color: #your-color;
    --secondary-color: #your-color;
    --accent-color: #your-color;
}
```

#### Update Content
Simply edit the text content in the relevant `.html` files to reflect your ventures' details, capabilities, and projects.
