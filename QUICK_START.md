# 🚀 Quick Start Guide

## How to View Your Website

### Option 1: Direct Browser Open (Easiest)
1. Navigate to the folder: `c:\venturesofsachinsridharan`
2. Right-click on `index.html`
3. Select "Open with" → Choose your browser (Chrome, Firefox, Edge, Safari)
4. The website will open and you can navigate through all pages

### Option 2: Drag & Drop
1. Open your web browser
2. Drag `index.html` from the file explorer into your browser window
3. The site will load

### Option 3: VS Code Live Server (Recommended for Development)
1. Install "Live Server" extension in VS Code
2. Right-click on `index.html`
3. Select "Open with Live Server"
4. The site opens at `http://localhost:5500` with auto-refresh
